# ZenexPay V1

ZenexPay is a Flutter + Supabase task/reward wallet platform with a React/Vite admin panel.

## Current V1 scope
- Email/password registration and login
- Responsive Android UI for small and large screens
- Published task browsing and secure task submission
- Server-side wallet balance protection
- Withdrawal request flow for bKash, Nagad and bank
- Transaction history
- Admin dashboard, user list, task creation, submission review and withdrawal processing
- Supabase Row Level Security and trusted database functions
- GitHub Actions Android release build scaffold

## Important
This project does not create fake earnings. Rewards must be funded by genuine tasks/business revenue. Automatic bKash/Nagad payouts require the appropriate official merchant/API integration and credentials.
