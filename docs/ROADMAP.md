# Build roadmap

## V1 foundation (current)
- Flutter Android app scaffold
- Supabase schema, Auth trigger, RLS
- Tasks and task submissions
- Wallet and secure withdrawal RPC
- Basic admin login/dashboard scaffold
- GitHub Actions APK build

- Private proof storage policies
- Submission review UI
- Referral reward rules tied to real platform revenue
- Notifications
- Transaction/history screens
- Production error handling and audit logging
- Payment provider integration only after merchant/API credentials are available
